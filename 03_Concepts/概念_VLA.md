# VLA（Vision-Language-Action Model）

## 定义

VLA（视觉-语言-动作模型）是结合视觉理解、语言推理和动作生成的多模态机器人模型。VLA能够根据视觉观察和语言指令生成机器人动作序列。

## 核心特征

- **多模态融合**：整合视觉、语言和动作
- **端到端学习**：从感知到动作的完整 pipeline
- **语言条件**：通过自然语言指定任务
- **泛化能力**：在新任务和环境中工作

## 技术架构

```
视觉输入 → 视觉编码器 (CLIP/ViT)
                ↓
语言输入 → 语言编码器 (LLM)
                ↓
        多模态融合层
                ↓
        动作解码器
                ↓
          动作输出
```

## 代表性模型

1. **RT-2**：Google的Vision-Language-Action模型
2. **OpenVLA**：开源的VLA实现
3. **PRTS**：TeleAI的课程强化学习VLA

## 当前挑战

1. **目标可达性无意识**：模型不知道距离目标多远
2. **长程规划困难**：难以处理多步骤任务
3. **泛化能力有限**：在未见任务上表现下降
4. **实时性要求**：需要快速推理

## PRTS的创新

TeleAI的PRTS模型提出了以下创新：

1. **课程强化学习（CRL）**：引入Q值函数评估目标可达性
2. **特殊Token设计**：`<CRL_action>`和`<CRL_goal>` token
3. **训练策略**：167B tokens大规模训练

## 发展趋势

- **与LBM融合**：结合大型行为模型的优势
- **强化学习集成**：引入RL提升决策能力
- **实时性优化**：降低推理延迟
- **跨平台部署**：在不同机器人平台上运行
