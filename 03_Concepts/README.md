# 03_Concepts

这里保存能连接论文和技术文档的概念页。

概念页是 Obsidian Graph View 中最重要的桥接节点。它们不属于论文目录，也不属于技术文档目录，而是用来把不同资料中的同一个思想连接起来。

## 创建条件

只有满足以下条件之一，才创建概念页：

- 概念同时出现在论文和技术文档中。
- 概念会反复用于理解多个资料。
- 概念可以连接论文、技术文档和项目。
- 概念足够具体，能支撑后续查询和复用。

## 不创建什么

不要创建空概念页。

不要创建过泛概念，例如：

- `概念_AI`
- `概念_技术`
- `概念_论文`
- `概念_学习`

## 推荐概念类型

优先创建可复用概念，例如：

- `概念_RAG`
- `概念_Agent`
- `概念_Tool_Use`
- `概念_向量检索`
- `概念_评估指标`

以上只是命名示例，不代表初始化时要创建这些页面。
