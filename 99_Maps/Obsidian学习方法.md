# Obsidian 学习方法

这份文档用于说明：以后你如何用 GrowthWiki 学习资料、积累概念、查看关系图谱。

## 1. 核心思路

GrowthWiki 的学习流程不是“收藏资料”，而是把资料编译成可以复用的知识节点。

```text
raw 原文 -> Claude Code 处理 -> Markdown 笔记 -> 概念连接 -> Graph View 观察 -> 输出理解
```

你主要学习的是 Markdown 笔记和概念关系，不是长期反复翻 PDF/DOCX 原文。

## 2. 每天怎么用

1. 把 PDF、DOCX 或原始 Markdown 放入 `00_Inbox/raw/`。
2. 在 `00_Inbox/intake.md` 里登记资料名称和状态。
3. 让 Claude Code 处理：

```text
处理 intake 里的全部待处理资料，按 CLAUDE.md 执行。
```

只处理一条时用：

```text
处理 intake 里的第一条。
```

4. Claude Code 会把资料编译成长期 Markdown：
   - 论文 -> `01_Papers/`
   - 技术文档 -> `02_TechDocs/`
   - 概念 -> `03_Concepts/`
5. 打开生成后的 Markdown 笔记阅读。
6. 打开 Graph View 看这些资料和概念之间的关系。

## 3. 默认关系图谱只看什么

默认 Obsidian Graph View 只显示三类真实知识节点：

- 论文笔记：`01_Papers/`
- 技术文档笔记：`02_TechDocs/`
- 概念页：`03_Concepts/`

默认不显示：

- `00_Inbox/`
- `00_Inbox/raw/`
- `README`
- `CLAUDE`
- `AGENTS`
- `intake`
- 模板
- map
- graph 说明页
- 使用说明

这些文件仍然有用，但它们是维护节点，不是学习图谱节点。

## 4. 学一个主题时怎么走

不要从文件夹一个个翻。优先从概念开始。

例如你想学 VLA：

1. 打开 `03_Concepts/概念_VLA.md`。
2. 看它连接了哪些技术文档、论文和相关概念。
3. 顺着双链跳转到相关节点。
4. 让 Claude Code 基于本地知识库总结：

```text
基于 D:\GrowthWiki 本地 Markdown 知识库，解释 VLA 和灵巧操作、课程强化学习之间的关系。
回答分成 Knowledge Base、Inference、Missing。
```

这样你学到的是“概念之间的关系”，不是孤立地读一篇文档。

## 5. Graph View 怎么看

Graph View 用来判断知识结构，不是用来追求好看。

看图时重点观察：

- 哪些概念连接了多篇资料：这是核心主题。
- 哪些技术文档只连了一个概念：说明还可以继续补充理解。
- 哪些概念和资料之间没有边：可能需要补链接，或者资料还没被充分消化。
- 哪些主题之间完全断开：可能需要补充桥接资料。

好的图谱应该自然变密，而不是靠空页面和虚假链接变复杂。

## 6. 读完一批资料后怎么复盘

可以让 Claude Code 做一次主题复盘：

```text
基于当前 GrowthWiki，整理最近新增资料的学习复盘：
1. 新增了哪些知识节点
2. 涉及哪些核心概念
3. 哪些概念之间出现了新的关系
4. 哪些地方还缺论文或技术资料支撑
5. 下一步建议读什么
```

也可以针对某个主题复盘：

```text
基于当前知识库，整理“VLA 目标可达性”的学习笔记：
1. 已有知识
2. 相关技术文档
3. 相关概念
4. 仍然缺失的信息
5. 下一步学习建议
```

## 7. 什么时候创建概念页

只有满足下面条件时，才应该创建概念页：

- 概念足够具体。
- 后续还会复用。
- 能连接论文、技术文档或多个主题。
- 不是为了让图谱看起来更大。

推荐概念：

```text
概念_VLA
概念_LBM
概念_灵巧操作
概念_课程强化学习
概念_仿真环境
```

不推荐概念：

```text
概念_AI
概念_技术
概念_论文
概念_机器人
```

## 8. 你最常用的指令

处理资料：

```text
处理 intake 里的全部待处理资料，按 CLAUDE.md 执行。
```

查询知识：

```text
基于 D:\GrowthWiki 本地 Markdown 知识库回答。回答时区分 Knowledge Base、Inference、Missing，知识库没有的不要编造。
```

检查图谱：

```text
检查当前知识库的双链质量：是否有空概念页、孤立页面、过泛概念、断链，以及哪些页面应该补充 cross-link。
```

生成学习路线：

```text
基于当前知识库，为我生成某个主题的学习路线：先读哪些技术文档，再读哪些论文，最后补哪些概念。
```

## 9. 最重要的习惯

- raw 是原料，不是知识。
- Markdown 笔记才是长期知识。
- 概念页负责连接。
- 双链负责关系。
- Graph View 是理解状态的投影。
- 学习的目标是能解释关系，而不是保存更多文件。
