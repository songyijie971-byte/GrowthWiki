# Graph Guide

Obsidian Graph View 是知识链接的结果，不是知识库的目标。

GrowthWiki 的图谱应该由真实双链自然生成：论文链接概念，技术文档链接概念，项目链接论文、技术文档和概念。

## Global Graph

Global Graph 用来看全库结构。

推荐观察：

- `01_Papers` 是否围绕概念形成论文群。
- `02_TechDocs` 是否围绕概念形成技术文档群。
- `03_Concepts` 是否真正连接论文和技术文档。
- `04_Projects` 是否把概念落到实践中。

## Local Graph

Local Graph 用来看单个页面附近的关系。

适合检查：

- 一篇论文连接了哪些概念。
- 一个技术文档能否连接到已有概念。
- 一个概念是否真的连接多个资料。
- 一个项目是否把论文、技术文档和概念串起来。

## Backlinks

反链用于判断一个页面是否有价值。

如果一个概念页长期没有反链，说明它可能过早创建、过泛或没有复用价值。

## 原则

- 目录负责分类。
- 双链负责关系。
- 概念页负责桥接。
- Map 页负责导航。
- 不为了图谱好看强行创建页面。
