# 01_Papers

这里保存论文/文献的整理笔记，只放已经阅读、理解、总结后的 Markdown。

## 放什么

- 论文阅读笔记
- 文献方法总结
- 实验设计分析
- 对自己有用的结论和可复用思路

## 不放什么

- PDF 原文
- DOCX 原文
- 未读收藏
- 未处理资料
- 导师资料、职业规划、个人复盘、生活记录

## 笔记要求

每篇论文笔记应至少包含：

- `Problem`
- `Method`
- `Experiment`
- `Conclusion`
- `Useful For Me`
- `Related Concepts`

每篇论文建议链接 2-5 个概念。概念链接应指向 `03_Concepts/` 中真实存在或值得创建的可复用概念。

不要为了图谱好看强行链接概念。
