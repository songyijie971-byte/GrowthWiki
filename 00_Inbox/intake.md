# Intake

这里是 GrowthWiki 的临时入口，只登记待处理的论文、技术文档、项目技术资料和 PDF/DOCX 原文。

不要在这里写日记、个人成长、情绪复盘、生活记录、导师资料或职业规划。

## 使用规则

- PDF/DOCX 原文临时放入 `00_Inbox/raw/`。
- Markdown 草稿或资料链接可以登记在本文件。
- 处理完成后，应生成结构化 Markdown 笔记，并放入 `01_Papers/`、`02_TechDocs/` 或 `04_Projects/`。
- 如果资料还没有编译成 Markdown，Claude Code 查询时应视为 `Missing` 或“尚未编译进知识库”。
